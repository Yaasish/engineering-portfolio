# GitHub publication checklist

This package is ready for a public repository, but it has not been uploaded or published automatically.

## 1. Create the portfolio repository

1. Sign in to GitHub and create a public repository such as `engineering-portfolio`.
2. Do not initialize it with another README or licence.
3. Upload the contents of this folder, keeping the directory structure unchanged.
4. Set the repository description to:

   `Computational mechanics, multiphysics, Abaqus, COMSOL, and engineering-prototype portfolio.`

5. Add topics such as `finite-element-analysis`, `abaqus`, `comsol`, `multiphysics`, `biomedical-engineering`, `fortran`, and `arduino`.

## 2. Create the profile README

1. Create a second public repository whose name exactly matches your GitHub username.
2. Copy `PROFILE_README.md` into that repository as `README.md`.
3. Confirm that portfolio links use your GitHub username (`Yaasish`).
4. Check that all three project links open correctly.

## 3. Final truth and privacy review

- Confirm the university GPA figures before adding them anywhere public.
- Keep the IMAT status as `submitted` until acceptance or publication evidence is found.
- Do not upload COMSOL `.mph`, Abaqus `.odb`/`.cae`, LabVIEW `.vi`, course ZIP files, or full manuscripts without a separate rights review.
- Do not upload confidential employer material, internal names, screenshots, product details, or performance claims.
- Keep a phone number off the public GitHub profile; email and LinkedIn are sufficient.
- Ask collaborators before publishing shared project files or photographs.

## 4. Make the links useful for applications

1. Pin the portfolio repository on the GitHub profile.
2. Add the portfolio URL to LinkedIn's Featured section.
3. Add the URL to the CV header after the GitHub profile is live.
4. For each application, link directly to the most relevant project as well as the portfolio homepage.

## 5. Recommended project order by role

- Simulation or computational-mechanics role: hydrogel, UMAT/auxetic, ultrasonic prototype.
- Biomedical or medical-device R&D role: hydrogel, ultrasonic prototype, UMAT/auxetic.
- Product, project, or engineering-operations role: portfolio homepage first, followed by the project that best demonstrates structured problem solving.
