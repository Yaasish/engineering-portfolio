# GitHub portfolio maintenance checklist

This repository is the public engineering portfolio. Use this checklist before future updates.

## Truth and privacy

- Keep the IMAT status as `submitted` until acceptance or publication evidence is found.
- Do not upload COMSOL `.mph`, Abaqus `.odb`/`.cae`, LabVIEW `.vi`, course archives, or full manuscripts without a separate rights review.
- Do not upload confidential employer material, internal names, screenshots, product details, or non-public performance claims.
- Keep the phone number off public GitHub pages; email and LinkedIn are sufficient.
- Ask collaborators before publishing shared project files or photographs.

## Hydrogel model release gates

- Keep the public Java artifact labelled as a solver-independent manifest, not a runnable COMSOL export.
- Align coordinate frames for all transport and electrostatic fields before a new solve.
- Remove or derive the isolated electrostatic scaling factor.
- Synchronize study and batch parameter lists.
- Complete mesh and time-step convergence checks before publishing a reproducibility claim.
- Regenerate figures from the cleaned model before describing the public source as a result-reproduction package.

## Distributor-system release gates

- Publish synthetic `.example` records only; never copy rows from the live spreadsheet or private exports.
- Keep the employer, live spreadsheet URL or ID, automation identifier, product criteria, competitors, target markets, source queries, and contact routes private.
- Describe the Python code as a sanitized reconstruction, not the private live implementation.
- Attribute the operational system as AI-assisted and distinguish Yasamin's workflow ownership from automated research and implementation work.
- Date every aggregate deployment metric and do not imply that it updates continuously.
- Do not claim hours saved until a comparable manual baseline and review-time sample have been recorded.
- Run the synthetic end-to-end tests and privacy checker before publishing.

## Make the links useful for applications

1. Pin the portfolio repository on the GitHub profile.
2. Copy `PROFILE_README.md` into the `Yaasish` profile repository as `README.md` when that repository is created.
3. Add the portfolio URL to LinkedIn's Featured section.
4. Add the URL to the CV header.
5. For each application, link directly to the most relevant project as well as the portfolio homepage.
